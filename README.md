# Many Miracles Ministries

Premium React web portal for an international prophetic and evangelical ministry focused on miracles, prayer, teaching, testimonies, evangelism and transformation.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React Icons

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Preview Build

```bash
npm run preview
```

## Deployment

The project is ready for Netlify or Vercel. Use `npm run build` as the build command and `dist` as the publish directory.
